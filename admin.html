Export & publishing steps

Export the working bank after reviewing all changes.

  1. Import your Excel file here.
  2. Check the import counts and make sure each question has the right subject, answer key and explanation.
  3. Click Download updated questions.js.
  4. Replace the existing questions.js file in your GitHub repository with the downloaded file and commit the change.
  5. Students will then receive the updated question bank when they open or refresh the GitHub Pages test.
Static-site limitation: this project has no central database. Importing into this admin page does not magically update other students' browsers. You must publish the exported questions.js to GitHub Pages. This admin page is not password-protected; do not treat it as secure access control. The answer key is client-side and can be inspected by technically skilled users.

Excel column guidance

Use the provided template columns: Subject, Topic (optional), Question Type, Question Text, Image, Answer 1 through Answer 10, Correct Answer(s), Explanation, optional Explanation Image Path, Explanation Image Alt, Explanation Image Caption, Points, and Negative Marks.

Use the floating ∑ Insert formula button after focusing a text field to insert formatted math/science notation. For PDF review, export the workbook, edit it, set the Approved column to Yes for verified rows, then use Import edited review Excel before importing approved questions.

For MC questions, set Correct Answer(s) to A, B, C, etc. For multiple response, separate letters with semicolons, e.g. A;C;D. For TF, use A for True and B for False. Review advanced formats after import before publishing.
